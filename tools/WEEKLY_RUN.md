# 매주 일요일 주간운세 실행 절차

이 저장소(marioai005-00/family-saju)는 GitHub Pages로 공개되는 가족 사주 사이트다.
매주 일요일 아침, 그 주(일요일~토요일) 아빠·엄마·딸 세 사람의 주간운세를 만들어 올린다.

## 순서

1. 이번 주 일요일 날짜를 정한다 (한국 시간 기준, 예: 2026-10-11).
2. 계산: `python3 tools/weekly_engine.py YYYY-MM-DD`
   - `data/week-YYYY-MM-DD.json` 이 생긴다. 출력된 요약(날짜·일진·월운·절기·점수·작용·숫자)을 읽는다.
3. 풀이 작성: `texts/week-YYYY-MM-DD.json` 을 새로 쓴다. 형식은 `texts/week-2026-10-04.json` 과 같다.
   - 사람별(dad, mom, daughter)로 `summary3`(3줄), `oneliner`(한 문장), `phases`(초반·중반·후반), `strategy`(5개 이내), `final`(3~6문장), `lotto_note`, `days`(날짜마다 `h` 오늘의 한마디 1~2문장, `say` 현암 선생 한마디 2~4문장)를 쓴다.
   - 반드시 `data/week-...json` 의 계산 결과(점수, 합·충 등 작용, 절기 변경, 숫자와 그 오행)에 근거해 쓴다. 숫자는 바꾸지 않는다.
   - 규칙은 `tools/WEEKLY_PROMPT.md`(주간운세 지시문)를 따른다. 단, 아래 표현 규칙이 우선한다.
4. 페이지 생성: `python3 tools/render_weekly.py YYYY-MM-DD`
   - `weekly/YYYY-MM-DD.html` 과 `weekly/index.html`(모음 목록)이 갱신된다. 한자가 섞이면 생성이 멈추니 문장을 고친다.
5. 커밋 후 main 브랜치에 푸시한다. 몇 분 뒤 https://marioai005-00.github.io/family-saju/weekly/ 에 반영된다.

## 표현 규칙 (현암 선생)

- 한자는 절대 쓰지 않는다. 사주 글자는 한글로만, 자연물로 풀어 쓴다 (예: 큰 강(임수), 토끼, 배우자·집 자리).
- 편한 존댓말(해요체). "~이오", "~하오" 같은 옛 말투 금지.
- 전문 용어는 쉬운 말 → (용어) → 나에게 무슨 뜻인지 순서로.
- 실제 직업·회사·일정·가족 사건 등 현실 정보를 근거로 쓰지 않는다. 사주 → 운 → 현실 가능성 순서만.
- 좋은 말 편향 금지. 점수가 낮으면 낮다고 말한다. 공포 조장, 사고·질병 단정 금지.
- 딸은 미성년자다. 업무는 공부·활동으로, 연애는 다루지 않는다.
- 로또 숫자는 재미·참고용 상징이며 당첨을 예측하거나 확률을 높인다고 쓰지 않는다.

## 숫자 선정 방식 (2026-10-08 변경)

- 간지→수는 선천수, 오행→수는 하도수 하나씩만 쓴다.
- 그날 일진·이달 글자·각자의 원국 글자·필요한 오행의 하도수를 엮어 후보 11개를 만들고, 이미 고른 번호·같은 끝자리·같은 번호대(2개 초과)·다른 가족의 번호와 겹치지 않는 후보를 고른다.
- 숫자는 `weekly_engine.py`가 정하며, 풀이 문장에서 바꾸지 않는다. `lotto_note`에는 필요한 기운의 분포와 끝자리 분포를 사실대로 적는다.
